# 架构起点

## Rust 核心

`crates/pandex-core` 承载跨平台领域模型与业务逻辑，不依赖 Tauri、Compose 或平台 SDK。当前仅建立 crate，后续按实际需求拆分模块，必要时再拆为独立 crate。

计划覆盖密码库条目、密码生成、密码库加解密与存储接口。密码学方案、数据格式及密钥生命周期需要在实现前明确，并采用成熟的密码学库。

## 客户端

`apps/desktop` 预留桌面应用，优先目标为 Windows，可评估 Tauri。

`apps/mobile` 预留 Android 与潜在的 iOS 应用，可评估 Kotlin / Compose Multiplatform 或 Tauri 移动端。

操作系统密钥存储、生物识别、剪贴板和自动填充等能力由平台适配层提供。若采用 Kotlin / Swift 客户端，再评估通过 UniFFI 等方案调用 Rust；若采用 Tauri，则通过命令接口接入核心。当前不生成这些绑定。

## 待定事项

- 威胁模型、主密码派生、密钥管理、锁定与敏感内存清理策略。
- 密码库文件格式、存储方式、备份与迁移机制。
- UI 框架、跨语言边界以及各平台最低支持版本。
- 本地优先与同步的范围、冲突解决策略。
- 开源许可证与发布签名方案。
